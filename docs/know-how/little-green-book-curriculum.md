# 小綠書課程設計 know-how（ENG-004）

對應 [SDD-004](../sdd/004-little-green-book-curriculum-design.md)、[16 單元設計](../curriculum/little-green-book-unit-sequence.md)與[施工紀錄](../devlog/2026-09-28-little-green-book-design.md)。

## 可重用的做法

1. **先定義覆蓋粒度**：一本書有單元、句型與長篇課文三層。「16 單元已設計」只表示每單元有可審閱的課程任務與對話草稿，不能說每一句、每個詞或 App 實作都已完成。工程索引同時標「設計／程式／上線」狀態。
2. **轉寫溝通功能，不改頭換面重演原文**：來源只提供「點餐」「澄清時間」等功能線索。換人物、情節、場所、資訊結構，撰寫新的短對話；不複製作者長段句子、人物、品牌、音檔。來源 PDF 留在使用者提供的位置，不進 repository 或 hosting。
3. **一課一個可觀察目標**：先說清學生要完成的事，再挑 4–6 個會阻礙理解的詞和 2–3 組主動句架。來源一單元若同時含機場、飯店、費用、升等，先選一個任務，其餘留補充或分課。
4. **順序不是難度**：保留來源 U01–U16 的導航順序，但 L1–L4 分級獨立。低程度學習者可在高難單元走「聽懂要點」支線，不強迫立即無稿辯論；本文的 L1+ 不新增 App level 值，也不宣稱 CEFR 等值。
5. **舊課不等於來源已改編**：現有「初次見面」「看醫生」只是相關題材。要有來源到課的明確設計／實作紀錄才能標為改編；`l1-07`、`l2-07`、`l2-08` 是目前真正依前案原創設計落地的三篇。新單元先找差異任務，避免複製同樣的對話。
6. **測量對應教學目標**：理解題測否定、數字、轉折與最後結果；換條件測能否傳達新需求，接受合理替代表達。聽過、跟讀過和自評「我會」不是客觀口說測驗。

## 易踩的坑與限制

- 「全部設計」容易被讀成「全部上線」。交付時務必同時報告單元藍圖數、正式課文數、音檔數與部署狀態。
- 來源較長或較專業的句型不應一股腦塞入初級課；醫療不講診斷或藥效，客訴不保證賠償，面試不鼓勵捏造經歷，新聞不使用未核實的現實斷言，文化議題避免讓學生背「唯一正確」立場。
- 版權與商用整體授權尚未稽核；即使是使用者提供的 PDF，也不等於可複製全文、音訊或素材。若未來進入商用，需另行盤點源素材與產音、字典等授權。
- 正式課程仍需內容 JSON、詞義/句界驗證、題目與提示審核、音檔、裝置 UI／離線與無障礙測試；文件中的 8 回合草稿不能直接當作已驗證教學成效。
