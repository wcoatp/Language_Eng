# 小綠書 U01–U04 審稿 know-how（ENG-005）

對應 [SDD-005](../sdd/005-little-green-book-u01-u04-editorial.md)、[審稿稿件](../curriculum/little-green-book-u01-u04-editorial.md)與[施工紀錄](../devlog/2026-09-28-little-green-book-u01-u04-editorial.md)。

## 可重用判準

1. **用新能力去重，而非只看題材**。現有自介課已能報姓名、問工作；U01 新增「根據對方回答追問」。現有點餐課已能選餐、外帶與付款；U03 新增「聽出另計並修復價格誤聽」。若說不出新能力，先做舊課變體或刪除，不另上架一篇同功能主課。
2. **短對話仍要有可追蹤的狀態變化**。U02 第 5 回合的分工先說錯，第 7–10 回合更正；理解題應問最後分工，不只抓第一個提及的人。U04 中途提到綠色，但最終買藍色小號；要測最後決定。
3. **詞卡必須在課內落地**。每個預習詞標來源回合、本課中文義與簡單英英義；例句獨立於故事，避免首聽前洩露缺貨、價格或最後選擇。正式 JSON 仍需校對 `surface`、詞形與句界。
4. **數字聽辨要有修復動作**。`nine / nineteen` 不能只出成單選題；讓學生練要求重說並重述品項。日後產音要真人聽評重音與速度，`ffprobe` 可解析不等於可辨識。
5. **提示是支援，不是能力證據**。無提示只給任務，第二層給關鍵字，第三層給可改寫句架；使用提示可自評「有提示完成」，不能自動記「獨立完成」。替代表達只看是否達成溝通目標。
6. **一個單元可對應變體而非新 lesson ID**。U01／U03 首選附加挑戰，U02／U04 才是獨立課候選。但目前課程資料模型是否支援同課多段對話尚未實作驗證，下一份實作 SDD 才定資料結構；設計文件不得先冒稱功能已存在。
7. **口語自然化要可替換、可分級**。同一意思只給 2–3 組清楚／自然對照，註明可主動練用或先聽懂。`My bad` 這類熟人說法不能強迫用在客服；`I'll pass for now` 可完成不買的真實任務。基礎說法本身正確，不因學生沒用俚語而判錯。
8. **口語聽辨要有回應，不只看單字表**。`nine / nineteen` 要接「請重說—對方澄清—學生確認」；社交追問、分工誤會、購物缺貨也各有短回應任務。設計時可標示 `I'm`、`I'll`、`We're out of` 等自然語流，但實際重音、弱讀與可辨識度須在產音後真人聽評，不把文字描述冒稱音訊測試。

## 風險與界線

- 來源 PDF 的句型表和情境課文只作功能參考；不直接複製長篇對話、角色、品牌、音檔。常見短句可能自然重合，但正式公開前仍需人工來源檢查；商用整體稽核另案。
- U01 不要求住址、聯絡資訊；U02 不把藥名或身體不適與家事一起教；U03 價格、貨幣與額外費用須在對話明示；U04 「不買」是可接受的真實溝通結果。
- 教師審稿與學生試用尚未完成。文件與既有程式測試通過，只證明結構與回歸，不證明課程難度或學習成效已最佳化。
