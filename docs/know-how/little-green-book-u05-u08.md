# Know-how｜把情境來源改編成分級、可教的 U05–U08

對應 [SDD-009](../sdd/009-little-green-book-u05-u08-editorial.md)、[ENG-009 施工紀錄](../devlog/2026-09-29-little-green-book-u05-u08-editorial.md) 與 [原創稿](../curriculum/little-green-book-u05-u08-editorial.md)。

## 可重用做法

- 先確認來源每個情境真正練的溝通功能，再跟既有課程比「學習者要完成的任務」，不要只比場景名詞。飯店對話不一定都重複入住；看醫生前的櫃檯登記也不等於完整問診。
- 每個新情境只留一個可觀察結果：描述設備現象並約時間、核對附加費、登記症狀與未知資訊、向道路支援說明位置並確認下一步。主目標越單一，詞卡與理解題越好對齊。
- 先列已有課和差異，再決定新增或延伸。前置課能降低詞彙負荷，但若學習行為不同，不要把「場景相似」當成已教過同一技能。
- 對話每句提供理解證據，題目標出回合 ID。答案應靠再次聽／讀能定位，而不是靠世界常識推理。
- 換條件任務避免只是替換人名；至少要改一項有意義的輸入（設備／症狀／價錢／時間／地點），讓學習者真正重新組織句子。
- L2 支援先提供關鍵詞、再提供句架；挑戰則加入協商、澄清或更新確認。這種梯度是教學假設，仍需老師審稿與學習者試教。

## 易踩陷阱與界線

- 不照搬來源角色、專有名詞、品牌、地址、劇情細節或長句；只取常見功能並以全新資料重寫。
- 旅館附加費要練明確確認，但不需學習者輸入真實信用卡／訂房資料；費率與總額用虛構數字。
- 醫療對話只教如何陳述已知與未知，不能讓課文暗示學生自我診斷、猜過敏或自行用藥。
- 車況與道路支援文本不要把預估說成保證，不要讓語言教材暗示學習者繼續危險駕駛，或保證可以索賠。
- 30 分鐘是產品節奏目標而非內容自帶的事實；每課六階段活動時間需有真實試用紀錄才可調整。
- 「10 回合、6 個詞、三道題」是本批編輯格式，不是證明教學效能的固定公式；教師／目標學習者回饋可改變它。
