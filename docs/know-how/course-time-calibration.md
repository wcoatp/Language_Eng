# Know-how｜不要把課程預算誤當成學習者實際用時

對應 [SDD-010](../sdd/010-thirty-minute-course-time-calibration.md)、[ENG-010 施工紀錄](../devlog/2026-09-29-thirty-minute-calibration.md)、[匿名試用紀錄表](../research/30-minute-course-pilot-template.md) 與[公式化空白活頁簿](../research/outputs/eng010-time-pilot-2026-09-29/30-minute-pilot.xlsx)。

## 為什麼既有資料不足

App 的六階段分鐘數相加為 30，是教學／產品配置。既有 stopwatch 為活動頁層級，不涵蓋預習、導覽、理解題與所有口說任務；每筆 session 也缺少完整課程 attempt 與 phase ID。因此將零散 session 加起來，不等同參與者完成一堂課的時間。

## 可重用採樣方法

- 每次試用記課程級別、課型及核心句數，並把六階段有效學習分鐘與牆鐘時間分開。
- 普通重聽、查詞和開口屬學習活動；電話、離開與休息另記。完成和部分完成分開分析。
- 只記匿名代碼和必要計數，不收姓名、錄音、逐字回答或可以回查身份的備註；預設本機保存。
- L1–L5 每級先取至少五位不同匿名學習者各一筆有效完成，再看中位數及 P75。重複代碼的試次可保留做描述，但不能增加不同學習者樣本數。小樣本只做初步描述；不要把單一課型、開發者估時或某位使用者代表整個級別。
- 空白活頁簿將原始輸入、首筆有效樣本與分級摘要分開。公式測試要同時驗證重複代碼、有效總分鐘、每階段中位數／P75，以及缺值不冒充 0；保存匯出檔前清除測試用臨時值。
- 只有總時間不夠：找出階段耗時、跳過、提示與重聽情形，辨別是活動設計、內容負擔、設備問題還是中斷；不應直接砍詞數或核心句數。
- 試用中途退出也是可用的流程線索，但不算有效完成樣本；應保留中止位置與原因類型，避免只看完成者而忽略課程卡點。

## 決策限制

未達每級樣本門檻，維持既有 30 分鐘設定並報「未校準」。若需要把資料收集改為 App 自動功能，先建立新 SDD，評估逐階段計時、暫停處理、裝置本機儲存、告知／同意、舊資料相容與刪除方式；不要為了量測方便自動上傳。
