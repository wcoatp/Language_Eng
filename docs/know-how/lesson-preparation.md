# ENG-002 know-how：預習與任務教學

對應 [SDD](../sdd/002-lesson-preparation.md)、[紀錄](../devlog/2026-09-22-lesson-preparation.md)。

- 聽懂與看到才懂是兩種自評；沒有播放成功不能記作聽辨成功。
- 簡短詞彙暖身不會把 L3 故事變 L1，不可改標程度。
- 預習搭配不提前播放劇透來源句；來源句只在精聽對答案或測驗回饋出現。
- 角色任務應承認語意等價，首版以自評而非 ASR 字串吻合度冒充溝通能力。
- 新內建課保持核心音檔齊全；只在裝置上的暖身／變化句需清楚標示發音限制。

## 實作與驗證結論

- 真正先聽模式不要只用 CSS 把字藏起來：首階段不要建立 term／翻譯／例句 DOM，也不要把答案放進播放鈕的 aria-label。
- 當裝置語音完成之後才解鎖聽辨自評；直接看字記 unavailable，而非猜測聽懂。看字後再次播放也不能回填成首次聽辨成功。
- 查詞與預習要分工：字典是一般多義工具，預習清單是編輯指定本課義及非劇透搭配。字詞暖身不提前播來源句。
- source surface 要用完整 token 範圍檢查，`inspect` 不能誤撞 `inspected`；`work. Out` 不應誤當片語。保留原形與實際詞形兩欄。
- 非同步畫面重繪會讓 focused button 消失。先保存焦點文字，重新渲染後尋找可用控制項，否則回標題；render／destroy 使用 epoch 抵抗舊資料覆蓋新路由。
- read → modify → write 即使用 Promise 串列也只保護單一頁面。用 IndexedDB 同一 readwrite transaction 的 onsuccess 內同步 reducer，才涵蓋跨頁交易串行。不要在 transaction callback 中 await。
- 題目 shuffle 必須保存 originalIndex，畫面第 1 個選項不是原 answer=0；同題重繪不得重新洗牌。紀錄原索引，可重算分數與稽核。
- 在角色卡看過句架後再切回「只有任務」，不能洗掉已用提示的事實。持續保存本輪 prompted flag，資料層再做獨立完成降為提示完成的保護。
- 固定角色卡不檢查實際回應；下一步是使用者自行推進，不宣稱能聽懂或自動判斷語意。
- 既有全域 Space 播放快捷鍵會攔截測驗按鈕的標準鍵盤點擊；對互動元素放行原生行為。
- 全程跳過精聽仍可能走到測驗與結束畫面。結束是一次流程，不是整課能力達標，也不代表所有句子進入 SRS。
- 內容產音工具可能報錯後仍以成功 exit code 結束，所以必須再跑 `validate-content`；不能僅看「命令完成」就說核心音檔齊全。
- 外部語音需傳送未發布原創文字時，先取得具體服務與資料範圍授權；安全審核拒絕後不換工具繞過。本機離線模型是不同資料流，不傳出課文。
- 授權單一課文不等於授權重製全課庫。既有工具只支援選聲音時，先以缺檔清單守衛確認所有外部待辦都在核准課程內，再呼叫；不要用 `--force`。
- 產音完成需分開檢查 manifest、每段實體 MP3 可解析與預覽 HTTP 回傳是否相符；這些都不等於逐句人工聽評。僅媒體／文件變動且 content 為 network-first 時，不必為此改動 app shell 版號。
- 每次 UI 修正後若 service worker 已安裝同版 shell，要升本地測試版號並走更新提示；重整頁面本身不保證取得同版的新檔。
