# ENG-001 施工紀錄

日期：2026-09-22。對應：[SDD-001](../sdd/001-word-lookup.md)。

## N1：規格與架構盤點（完成）

- 使用者授權開始施工；商用完整評估暫緩。本輪不提交／推送／部署。
- 工作樹原有未追蹤的設計提案與 PDF，保留不動。
- 現有 app 是純靜態 PWA；課文 row 點擊會播放整句，精聽先隱藏文字。查詞需隔離事件並尊重盲聽。
- 目前 IndexedDB kv 足以新增少量狀態。設定頁只有匯出，沒有還原，不把還原列為已支援。
- 公開 MediaWiki API 已以 `work_out` 驗證返回 English 區段、釋義、翻譯區與 revid。網路需工具環境權限；這不是 App 端授權方案。
- 決策：首版內建自編小詞庫＋按需查維基詞典，避免同時導入兩個外部詞庫；保留來源，不展開商用法務工作。
- 建立根目錄工程規則與工程索引，後續施工必須先有 SDD。

## N2：字典核心與測試（完成）

- 新增 110 個自編詞條、明確詞形對應、8 組精確課／句覆寫、同句片語判定。
- 新增按需維基詞典查詢；區分 not-found、斷線、逾時、取消；不按索引硬配中英文詞義。
- 新增 12 項 Node 回歸測試；整套 44 項通過。瀏覽器 DOM 抽取另有專用驗證頁，實跑結果見 N4。

## N3：UI、收藏與匯出（完成）

- 共用 native dialog 字卡：英中／英英切換、原句、裝置發音、來源、收藏。
- 整合課程預覽、播放、精聽揭示文字階段；把整句播放移到明確的 ▶ 按鈕。
- 連續播放查詞時暫停，手動續播才重播被中斷的一句；不將查詞計入句子掌握。
- 收藏在設定頁可查看；匯出包含 vocabularyBookmarks。快取有 100 筆上限。

## N4：版本與驗證（本機已執行範圍完成）

- 本地版號 `2026.09.22.1`；sw shell 加入三個字典模組。
- Firebase 排除 `AGENTS.md` 與 PDF，避免未追蹤附件在未來發布時被 hosting 一併收錄。未移動或刪除附件。
- 初次 `npm run check`：51 個 JS 模組語法、44 項測試、108 課／1840 句／12380 音檔全部通過。
- 本地預覽 server 在沙箱內不能綁定 port，改請求只綁 localhost 的執行權限；不是部署。
- 瀏覽器 fixture 初次抓到舊式 `<h2><span id="English">` 抽取失敗；修正 heading 外層定位後重跑通過。
- 本機曾有舊 service worker，造成新舊模組混用（`fallbackChain` export 錯誤）與舊 CSS。透過僅限 localhost 的 QA 按鈕解除該 origin worker、關閉舊頁重開；沒有刪除 IndexedDB、音檔或快取。這是測試環境復原，不等同正式站升級已驗證。
- 390 × 844 與桌面畫面實看：字卡、雙語按鈕、原句與收藏沒有版面溢出；測試後還原視窗尺寸。
- 課文 s7 點 `work` 顯示 `work out` 的本句「推算；弄清楚」；英英切換正確；精聽 `coming` 回原形 `come`。
- 真實線上查詢 `work out` 成功：英文釋義、中文翻譯群組、來源與修訂版號可見；簡體來源明確標示，不冒充繁中。
- 最終補測未內建的 `laptop`：初次明示未收錄；按需線上查詢成功；關閉重開後不再按查詢，直接顯示翻譯與「裝置快取」。此項在有網環境驗證 cache 命中，非飛航模式測試。
- 實測收藏 → 設定頁重開 → 移除後清單更新；已移除本輪建立的兩筆測試收藏。匯出欄位有自動檢查，未實際下載備份檔或驗證還原。
- 連續播放第 1 句查詞後保持暫停；關閉仍顯示續播鈕，手動續播仍是第 1 句。補上句間停頓也需等待查詞關閉／手動續播的防護；未以真機精準觸發句間邊界。
- 盲聽無查詞元素，對答案後才出現。無障礙檢查發現既有模糊文字仍能被讀出，因此補 `aria-hidden`；最終重開確認盲聽 AX tree 不含答案。
- 字卡非同步重繪曾讓焦點離開；修正停用按鈕時回到關閉鈕。實測收藏後焦點仍在字卡；Tab／Esc 與返回原單字通過。播放器重繪後原按鈕消失時改回主內容。
- 瀏覽器驗證頁最後 9 項全部通過；涵蓋英語區段、翻譯群組、安全抽取、舊 heading、原句保留、同句選取按鈕、焦點、關閉時非同步載入競態。
- 最終 `npm run check`：51 個 JS 模組、44 項 Node 測試、108 課／1840 句／11 組聲音／12380 音檔通過；`git diff --check` 通過。
- 直接開精聽深連結時遇到瀏覽器 `not-allowed` 自動播放限制；先使用者點擊播放即可，未改變瀏覽器權限。未測麥克風、實機發音品質。
