### N2｜四課內容轉製與自動檢查

- 新增 4 份 lesson JSON：合計 40 句英中對話、24 個詞卡、12 題證據式理解題、12 組三步換條件任務與選修口語練習。

- 兩項本批測試通過：四課 ID／順序／句數結構；教材、詞卡引用、題目證據、任務、30 分鐘且全文 10/10 核心路徑。

### N4｜固定音檔與傳輸邊界

- 本機 Kokoro 美式／英式各完成 40 段，`ffprobe` 80/80 均可解析且 duration > 0。只產生新課缺檔，未改寫舊課音檔。
- Edge US/GB 產音需要把 40 句原創英文傳到 Microsoft Speech。沙盒網路測試失敗並留有 12 個零位元組檔；已逐一核實並只清除該 12 個新課空檔。
- 後續受保護網路請求被自動審查拒絕，原因是未發布教材文字送往外部目的地需另行授權；沒有繞道或再次嘗試，已透過產品提問工具詢問使用者是否僅允許這 40 句用於 TTS。
- 因 Edge 尚未產生，manifest 只應含 Kokoro 80/160 份完整內容；發現失敗嘗試留下的 `l2-09` Edge 1–6 段清單並移除，因為對應音檔不存在，不能宣告成可播內容。
- Edge 兩組音檔仍缺 80 段；授權未到前不再嘗試外傳，也不部署這個未達 SDD 音檔門檻的版本。

### N5｜手機版與發布門檻檢查

- `npm run check` 的語法檢查與全部 76 個 Node 測試通過；內容驗證明確失敗在四課各缺 Edge US／GB 核心聲線，共 8 個發布阻擋項。這是音檔未完成的預期阻擋，不以寬鬆驗證繞過。
- 內容索引為 119 課／1,956 句；README 也區分了目前本機內容庫與尚未更新的正式站版本。

### N6｜延伸 smoke test 與音檔端點

- 再驗課程庫、`l2-09` 詳情及連續播放控制頁的 390×844 排版；四堂均列在 119 課清單，課程頁提示有 3 題理解測驗，播放頁顯示 10 句及聲線／速度控制。`scrollWidth` 仍為 390；未實際播放聲音，理解測驗互動也尚未走完。
- 以 `ffprobe` 重驗四課 Kokoro 美／英共 80 段，每段均有正時長；專案預覽服務保持運作，已成功回應內容索引、課程 JSON 及音檔 manifest。這些檢查不替代 Edge 音檔或人工聽評。
- 外部授權尚未收到；未生成 Edge 音檔，未更新發布版號，未 commit、push 或 deploy。

### N7｜Kokoro 批次技術音質掃描

- 對 80 段 Kokoro 音檔逐檔重跑 `ffprobe`：均有效；時長範圍 1.178–4.169 秒，位元率 49,091–52,456 bit/s。
- 對 80 段逐檔 `ffmpeg volumedetect`：均可解碼；平均音量範圍 -27.4 至 -22.6 dB，峰值範圍 -11.9 至 -3.3 dB，無接近 0 dBFS 的削波，也沒有平均音量低於 -35 dB 的極低音量檔。
- 這是檔案／波形層級的技術篩查，不能判斷發音自然度、角色區分、數字或否定的可懂度；目前不依波形數字自行做壓縮或音量正規化，保留真人聽評。

### N8｜限定外傳範圍並產生 Edge TTS

- 使用者明確授權只將 U05–U08 的 40 句原創英文傳送給 Microsoft Edge TTS；本節點沒有傳送 PDF、中文、其他課程、個人資料或學習紀錄。
- 為避免產音器預設掃描全庫，先在 SDD-011 增列 EAI-08，再新增 `tools/voice-scope.mjs` 的白名單式 lesson 選擇；Edge 呼叫缺少 `--lesson` 或遇到重複／未知 ID 會在開始生成及寫 manifest 前中止，測試同時比對拒絕前後 manifest 未變。
- 此批精確命令：`node tools/generate-voices.mjs --voice edge-us,edge-gb --lesson l2-09,l2-10,l2-11,l2-12`。產音器明確回報 4 課／40 句；40 個英文句子各送兩種 Edge 聲線，輸出 Edge US／GB 各 40 個 MP3，共 80 段。
- 四個目標課程目錄各有 10 段；80/80 非空、逐檔 `ffprobe` 可解碼且 duration > 0，總大小 1,995,552 bytes，時長範圍 2.160–5.952 秒；四課 manifest 句序逐一比對一致。沒有重產 Kokoro 或其他課程音檔。
- 將四課完整性測試改為要求 Edge US／GB 加 Kokoro US／GB 四組句序全等；`package.json` 的通用 `audio` 限為本機 Kokoro，Edge 另提供需附帶 `--lesson` 的命令，`audio:all-local` 不包含外部 Edge。
- 桌面預覽 `l2-09` 詳情與 10 句連續播放頁可正常呈現；先前 N5/N6 390×844 檢視保持原紀錄。這輪仍未人工聽完各音檔，也未走完理解題互動或實機測試。
- `npm run check` 通過：65 個 JS 模組語法檢查、81/81 Node 測試、內容驗證 119 課／1,956 句／11 voice sets／12,844 段音檔。此結果確認工程完整性，不代表教師審稿、音質主觀驗收或真人教學研究完成。
