# SDD-005：小綠書 U01–U04 教學審稿與實作準備

工程 ENG-005；建立：2026-09-28；狀態：第一版審稿與口語文字增補完成，仍待使用者／教師內容審閱、音檔聽評與另案實作。承接 [SDD-004 全書藍圖](004-little-green-book-curriculum-design.md)；後續「好 下一步」承接使用者同意的口語自然化方向，不直接發布未審草稿。

## 非目標

- 不把四份稿件直接轉成 App 課程，不新增正式 lesson ID、音檔或 service worker 資源。
- 不重新撰寫所有既有 L1 課，U01／U03 優先作辨識能力不同的變體；App 若需新增「變體」資料型別，由後續實作 SDD 決定。
- 不以附件每一條高頻句都要練到為目標；本輪每課只求一個可觀察的溝通成果。
- 不做商用授權結論，也不以 AI 或自評充作真人教學成效驗證。
- 不為了「更口語」堆疊美式俚語、口音模仿或未經校對的拼寫式縮音；基礎清楚說法仍是正確且可接受的答案。

## 設計／資料流

PDF U01–U04 句型頁及完整課文 → 與現有四課逐句對照 → 選唯一新功能 → 10–12 回合原創對話 → 5 個課內義詞卡 → 3 題首聽理解 → 不同條件任務及三層提示 → 清楚／自然說法對照與聽辨修復 → 編輯檢查 → 對照 SDD 驗收。

審稿文件位於 [U01–U04 實作準備稿](../curriculum/little-green-book-u01-u04-editorial.md)。它是人審內容，不是機器可直接載入的課程 JSON；正式課程欄位、聲音與離線配置都要另行驗證。

## 相容性與風險

- 保留 App 的 L1 整數等級；L1+ 僅為同級延伸的教學標記，不新增 level 值。避免把 U01／U03 與既有自介／點餐課重複上架。
- U01 社交追問不要求提供住址、聯絡方式；U02 不導入藥物建議；U03 價格與加購資訊要在對話明說；U04 允許「不購買」作合法任務結果。
- 來源 PDF 留在使用者原處；對話只借用生活溝通功能，人物、情節及措辭自行創作。商用整體稽核另案。
- 口語替代句不覆寫既有台詞，也不讓任務評分依賴某一個縮讀或俚語。若日後製音，需實際聽評自然重音、弱讀與可辨識度；文字標記不能替代音檔驗證。
