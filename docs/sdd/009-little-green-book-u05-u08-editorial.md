# SDD-009｜小綠書 U05–U08 教學審稿與新增課程判定

- 工程項目：ENG-009
- 狀態：原創設計稿完成並進入 ENG-011 App 轉製；未完成教師審稿或真人試教，發布狀態以 ENG-011 為準
- 上游：SDD-004（U01–U16 藍圖）、SDD-005（U01–U04 審稿方法）
- 來源頁次：使用者提供 PDF 第 58–72 頁（U05 58–60、U06 61–65、U07 66–69、U08 70–72）

## 背景與需求

使用者要求接續小綠書課程設計，並在寫入 App 前先判斷現有課程是否已教過相同溝通功能。U05–U08 原始素材包含專業維修估價、入境個資與旅館升等、醫療症狀與診療、租車故障與賠償爭議。本輪只改寫可遷移的生活溝通目標，限縮不適合基礎課的高風險或高負擔內容。

| ID | 需求 | 驗收條件 |
|---|---|---|
| LGU-01 | 逐單元核對來源與既有課 | 設計稿標出來源頁次、學習目標、既有相近課、差異能力與採用「承接／新增」的理由 |
| LGU-02 | 形成可供教師審稿的原創內容 | 每單元有 4–6 詞、8–12 回合雙語對話、3 題含證據的聽力理解、換條件任務、分層提示與自然說法 |
| LGU-03 | 維持 L2 難度而不把來源順序誤當學習等級 | App 等級候選為整數 L2；每課提供低負荷支援與較高挑戰，不宣稱 CEFR 等值 |
| LGU-04 | 優先消除重複課程 | 明確辨認 U05／L3-02、U06／L1-04 與 L2-07、U07／L2-04 的重疊，並說明新增目標如何不同；U08 檢查租車／道路救援等現有課 |
| LGU-05 | 降低來源與安全風險 | 不沿用來源人物、品牌、地址、劇情或長句；不要求真實證件、信用卡、地址、病歷或保險資料；醫療不診斷、不建議用藥；道路故障不鼓勵冒險駕駛、不保證賠償 |
| LGU-06 | 教學成效不冒稱已證明 | 理解題只證明所選資訊理解；任務自評不等同口說評分；本輪不宣稱學生試用成效 |
| LGU-07 | 工程追溯完整 | 規格、審稿稿件、施工紀錄、know-how 與工程索引可互相連結 |

## 非目標

- 不修改 lesson JSON、課程索引、App、Service Worker、音檔或版本號。
- 不替尚未決定的課程編造正式 lesson ID；U05–U08 是否新增課程，最終由內容審稿與後續實作 SDD 決定。
- 不逐句翻譯／複製附件，不使用原作者人物、公司品牌、私人地址、交易資料或音檔。
- 不執行商用整體授權稽核，不宣稱此設計稿可直接商用。
- 不把六階段 30 分鐘預算當成已由學習者驗證的真實課程時間；時間實測依 ENG-010。

## 差異設計決策

| 單元 | 既有相近課 | 本單元候選獨立目標 | 暫定判定 |
|---|---|---|---|
| U05 住家維修 | `l3-02` 有熱水與滲水、房東協調，句長及議題較進階 | L2 學習者描述一項可觀察故障現象，約定技師到訪時段；不診斷、不談租金或估價 | 新增 L2 前導課候選，之後可連到 `l3-02` |
| U06 旅行與住宿 | `l1-04` 基本入住；`l2-07` 房間未備妥與確認時間 | 入住時問清一筆額外費用是否已含、每晚計價及多晚總額，再明確確認 | 新增 L2 費用確認變體候選；沿用前兩課作先備，不重教登記／等待 |
| U07 健康與醫療 | `l2-04` 病人與醫師問診，包含症狀及醫療建議 | 在診間櫃檯簡短交代症狀與開始時間；對不確定的過敏資訊如實表達並請醫療人員確認 | 新增 L2 登記前導課候選；不取代 `l2-04` 問診課 |
| U08 客訴與抱怨 | `l1-07` 是餐點售完後改點；目前未見租車道路救援課 | 安全停車後描述警示燈／問題、提供安全可辨認的位置、問救援方式並確認預估等待與下一步 | 新增 L2 客服修復課候選；不涉及賠償權利結論 |

候選 ID 一律留待正式實作 SDD 檢查當時課庫後再決定。若審稿認為其中一項可在既有課加選修支線完整達成，需重新評估是否避免新增獨立課。

## 設計／資料流程

來源 PDF 的單元目的與句型功能 → 逐課盤點既有 lesson → 選一個可觀察溝通目標 → 換新角色與資料重寫對話 → 詞卡／理解題／換條件任務 → L2 支援與 L3 挑戰 → 安全／重複檢查 → 教師／使用者審稿。審稿稿件只作人類內容檢視；若通過，再由另一份 App 實作 SDD 決定課程資料、路由、音訊和上線方式。

## 相容性

- 沿用現有整數 `level`，L2 是設計候選，不擴充等級系統。
- 設計階段不改 ID、路由、IndexedDB、學習進度、音訊 manifest、備份格式或離線快取。
- 優先用前置／後續課的導航關係連結相近課；不把相近題材寫成「已教過本功能」。
- 使用者附件仍在本機原位置，不加入 Git、內容索引、測試或 Hosting。
