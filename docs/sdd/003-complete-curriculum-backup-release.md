- 新增提案 B「房間還沒準備好」及 C「這天不行，換一天好嗎？」兩課，包含預習、理解題、換條件任務與四組核心音檔。

- 不新增 ASR 客觀任務評分、AI 自由回應評分，也不一次擴寫購物、家事、報修、訂單有誤等尚未設計的課程。

## 設計與資料流

### 全課預習

`getLesson()` 載入課程後呼叫純函式補上自動 `learning`。既有人工欄位原樣保留。自動選詞只使用課文英文、內建詞庫與固定停用詞：先挑可提供本地英中／英英的完整單字或片語，再以重複、位置及長度挑內容詞補足。不得傳送全文。

自動項目標記 `automatic`／`lookupRequired`。未收錄項目只顯示「需查詞確認」，由學習者明確按既有「查開放字典」才傳送單一字詞。預習的聽辨自評與詞義確認仍分開；未打開可用解釋的項目不能記為「看字也懂」。自動版本由規則版號與課文內容 hash 產生，課文或演算法改變時只重置該課預習進度。

### 課程關聯

`learning.prerequisite` 與 `learning.next` 取代頁面硬編課號。內容驗證確認目標存在且不自我指向。新課接在 `l1-04 → l2-07`、`l2-01 → l2-08`；既有 `l1-05 → l1-07` 同步改成資料關聯。

### 備份與還原

新格式：`{ format: "echo-backup", version: 1, exportedAt, appVersion, stores }`。`stores` 含七個 IndexedDB store 的完整資料；Blob／ArrayBuffer 以有型別標記的 base64 表示。匯出時從 `kv/settings` 移除 API key。解析採大小、格式、store、主鍵與危險物件鍵驗證；也接受 2026-09-22 舊式「學習紀錄」匯出並轉成新版 stores。

還原前先讀檔及顯示日期／筆數，使用者確認後才執行。七個 store 在單一 readwrite transaction 中先清除再寫入；任何錯誤 abort。還原後把還原設定與本裝置原 API key 合併，重新載入 App。離線音檔 cache 不屬學習資料，不放進 JSON。

## 相容性與安全

- 純靜態 PWA，無後端與新框架；舊課 JSON 不必批次改寫。
- 自動候選是教學輔助，不冒稱人工課程編輯或 CEFR 認證；人工內容仍是品質最高層。
- 新課為本工程原創；只有使用者明確同意後，Edge 才會收到新兩課的 22 句英文以產生 44 段美／英式音檔，Kokoro 使用本機模型。附件、個資與學習紀錄不進產音服務。
- 備份檔是使用者主動下載／選取；還原不接受程式碼、HTML 或外部 URL。API key 不出現在備份。
- 部署沿用 Firebase Hosting，先 check、驗收、commit、push，再 deploy；任一步失敗即停止後續步驟並記錄。
