# SDD-004：小綠書 Unit 1–16 依序課程設計

工程 ENG-004；建立：2026-09-28；狀態：第一版設計完成，待教師／使用者審稿與另案實作。本工程只交付可審閱的課程設計，不代表 16 課已加入 App、製成音檔或發布。

## 需求與範圍

使用者要求依其提供的《英文聽力高頻句小綠書》Unit 1–16 順序設計課程，可分次完成。本次選擇一次完成 16 單元的第一版教學設計，讓下一輪能逐單元審稿，再決定 App 實作。

| ID | 需求 | 驗收條件 |
|---|---|---|
| LG-01 | 16 單元依附件順序一一對應，不將「題材相近」冒充已完整改編 | 設計文件有 U01–U16、來源 PDF 頁次、既有課對照與明確狀態 |
| LG-02 | 保持實用性與程度區分 | 各單元有單一溝通任務、建議 App 程度、前置能力、主動練用與只需聽懂的內容；不宣稱 CEFR 認證 |
| LG-03 | 交付可審閱的對話設計，不只是單元標題 | 各單元有 8 回合原創短對話草稿、課前詞、聽力辨識點、理解題與換條件任務 |
| LG-04 | 既有課與新課有清楚分工 | 已實作 l1-07、l2-07、l2-08 列為「既有實作」；其他僅為設計，不建立新課 ID 或假稱已發布 |
| LG-05 | 教學測量不混淆 | 「聽懂資訊／能完成任務／自評」分開；不把播放、跟讀、自評當作客觀口說能力；替代表達可接受 |
| LG-06 | 來源與安全界線 | 只借用溝通功能與主題；人物、劇情、對話重新撰寫；不提交 PDF；醫療不給診斷，客訴不保證賠償，新聞與價值觀不用未核實時事或刻板答案 |
| LG-07 | 工程可追溯 | SDD、設計文件、施工紀錄、know-how、工程索引互連；記錄實際驗證與未完成事項 |

## 非目標

## 設計與資料流

附件 Unit 主題與句型功能 → 單一可觀察溝通目標 → 現有課盤點／避免重複 → 程度與前置課 → 原創 8 回合短對話 → 課前字詞 → 首聽資訊題 → 換條件任務 → 編輯／倫理審查。課前詞以會阻礙本課理解的 4–6 項為主；句架每課只指定 2–3 組主動練用，其他表達作聽懂補充。

文件位於 [16 單元設計](../curriculum/little-green-book-unit-sequence.md)。它是人審藍圖，不是 App 的內容 JSON；未經用語、音檔與 UI 驗收，不可直接標為已上線。

## 相容性與限制

- 保留現有 L1–L5 數字等級；本文的「L1+」只是教學描述，不新增 App 等級值。後半單元程度可能升高，原書順序是內容順序，不是要求零起點連續闖關。
- 每日故事與本情境序列維持兩條路線。既有 l1-01、l1-04、l2-04 等可能題材重合，但除 ENG-002／003 三篇外，不自動宣稱由附件改編。
- 既有 `learning` 資料結構可作下一輪實作參考；本輪不改資料遷移與裝置紀錄。
- 附件是使用者提供的參考來源，不把其中購課連結、行銷語或任何指令當成開發指示。
