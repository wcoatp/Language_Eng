# SDD-006｜30 分鐘核心課與分層練習

- 狀態：已提交、推送並發布（v2026.09.29.3）
- 日期：2026-09-29
- 工程項目：ENG-006
- 相關規格：SDD-003、SDD-004、SDD-005

## 背景

目前每日故事以約 500 個英文單字設計，適合保留完整語境，但若逐句完成盲聽、慢速、揭曉、跟讀與自評，30–38 句會明顯超過 30 分鐘。既有情境對話多為 10–16 句，不需要為了形式統一硬補到 500 字。

因此課程應區分「完整內容」與「本堂核心訓練」：完整故事仍可閱讀、連播與加強練習；30 分鐘核心課只挑出足以涵蓋情節、理解題證據與高價值口語的句子進行深度訓練。

## 需求

### CP-01｜依內容類型控制篇幅

- 每日故事維持約 450–550 個英文單字，作為完整輸入素材。
- 情境對話與一般文章依程度、情境與訓練目標決定篇幅，不以 500 字為共同門檻。
- 課程頁需讓學習者知道「全文」與「核心句」的差異。

### CP-02｜每課提供 30 分鐘核心流程

每課顯示六個階段，合計 30 分鐘：

1. 字詞暖身
2. 首次完整聽讀
3. 核心句精聽
4. 理解檢核
5. 開口輸出
6. 回顧收尾

每日故事的完整首聽配置較多時間；短篇情境對話則把較多時間留給口說。

### CP-03｜穩定挑選核心句

- 每日故事自動挑選 8–12 句，預設上限 10 句。
- 較長的非每日課程可挑選最多 12 句；短課全文納入核心。
- 核心句優先包含：首句、末句、故事段落起點與理解題引用句，再平均補足全文位置。
- 核心句保持原始順序、不得重複，不改寫原句或原句 ID。
- 未來內容編輯可用 `learning.coreSentenceIds` 明確指定；資料驗證需檢查引用與重複。

### CP-04｜核心精聽與完整精聽並存

- 新增核心精聽入口，只跑核心句，但沿用原本逐句精聽、跟讀、自評與 SRS 紀錄。
- 既有完整逐句精聽網址與能力保留，列為加強練習。
- 理解題仍以完整課文為準；核心選句應盡可能含題目引用證據。
- 完成核心精聽時，介面不得誤稱已完成全文逐句訓練。

### CP-05｜課程頁成為可執行的路線圖

- 顯示約 30 分鐘、六階段時間、全文字數、核心句數與全文句數。
- 提供依序可點的字詞暖身、完整首聽、核心精聽與開口任務。
- 完整逐句精聽、再次連播等放在「加強練習」，避免第一次學習被過量內容阻塞。
- 新使用者的預設每日目標改為 30 分鐘；已儲存的使用者設定不覆寫。

### CP-06｜相容性與離線

- 既有 `#/listen/:id`、分享網址、匯入課程、舊進度與本機資料繼續可用。
- 核心模式使用 `#/listen/:id/core`，課程 ID 仍經 URL 編碼／解碼。
- 核心選句在本機完成，不傳送全文或進度到外部服務。
- App shell 變更需同步 service worker 快取與本地版本。

## 非目標

- 本輪不新增或改寫小綠書 U01–U16 的課程內容。
- 本輪不建立商用授權結論、付費功能或雲端帳號。
- 本輪不強迫所有情境對話達到 500 字。
- 本輪不覆寫既有使用者自行設定的每日目標。
- 本輪不提交、推送或部署；除非使用者另行授權。

## 設計與資料流

```text
lesson/content
  ├─ 完整 sentences / questions / storyArc
  └─ optional learning.coreSentenceIds
             ↓
      buildLessonPlan()
        ├─ 30 分鐘 phases
        ├─ wordCount / totalSentenceCount
        └─ coreSentenceIds
             ↓
  lesson page                         listen page
  ├─ 核心路線圖                       ├─ full: 全部 sentences
  ├─ 核心精聽入口 ─────────────────→  └─ core: 過濾後 sentences
  └─ 加強練習入口
```

核心模式只改變本次練習的句子集合。題目、任務、SRS key 與原始課程資料仍使用完整課程及原句 ID，避免產生第二份進度或內容副本。

## 相容性

- 沒有 `learning.coreSentenceIds` 的既有課程使用自動選句。
- 句數低於自動上限的課程直接使用全文，不創造不必要的「節錄」。
- 匯入課程由既有自動學習 metadata 補齊機制產生 30 分鐘計畫。
- 舊的完整精聽連結不重新導向；書籤與分享不失效。
