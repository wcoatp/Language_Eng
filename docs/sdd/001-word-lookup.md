# SDD-001：點字查詞

工程：ENG-001。建立：2026-09-22。狀態：本地首版實作完成；已執行驗收與未測範圍見施工紀錄；尚未發布。

## 目的與範圍

在課程預覽、完整播放與精聽揭示文字後，直接查詢英文單字／片語，切換英中與英英解釋，支援發音及生字收藏。保留本句詞義優先與一般字典的差別。

非目標：本輪不新增三組基礎對話、不做完整課前預習流程、不做 AI 自動判義、不重新設計 SRS、不做商用整體稽核、不提交／推送／部署。其他畫面與全系統跨 App 查詞不在首版範圍。

## 需求與驗收

| ID | 需求 | 驗收方式 |
|---|---|---|
| WL-01 | 點字可查；拖選同一句內 1–6 個英文詞可查片語 | 桌面／窄螢幕 UI；標點、縮寫、連字號測試 |
| WL-02 | 英中／英英切換；詞性、來源與缺漏狀態可見 | 本地詞與線上詞 UI；缺中文不假造 |
| WL-03 | 精確的課／句詞義覆寫優先；可由常見變化形回原形 | `work out`、`record`、`inspected` 測試；一般字典不得標成自動判定本句義 |
| WL-04 | 查詞不觸發整句播放；盲聽不洩露文字 | 事件與 UI 驗收；播放器查詞暫停，關閉後不擅自續播 |
| WL-05 | 內建小詞庫離線可用；外部查詢需使用者按鈕啟用 | 禁網測試、本地 cache 命中、失敗可重試 |
| WL-06 | 外部服務只收到選取詞，不傳全文或學習資料 | fetch URL／credentials／referrer 測試；UI 明示 |
| WL-07 | 收藏保存字詞、課文位置、已知解釋與來源；設定可查看及匯出 | IndexedDB 與匯出驗證；不得改變句子熟練度 |
| WL-08 | 彈窗可用 Esc／關閉按鈕；焦點留在彈窗，關閉回原處 | 鍵盤與窄螢幕測試；路由離開關閉 |
| WL-09 | 快速換詞、關閉與失敗不能顯示舊回覆 | race／abort 測試 |
| WL-10 | PWA shell、版本、文件與測試一致 | `npm run check`；工程索引追蹤 |

## 設計

### 資料流

課文文字 → 安全分詞／同句選取 → 本課詞義 → 內建詞庫／已快取的一般詞條 → 使用者按「查開放字典」→ 維基詞典 → 只提取文字 → 字卡與限量快取。

- `js/dictionary-data.js`：少量自編英中／英英解釋、常見變化形與針對課／句的詞義覆寫；不匯入整本附件。
- `js/dictionary.js`：純函式（分詞、正規化、詞形、範圍判定）、外部查詢與結果抽取。維基詞典是首版單一外部來源；先不引入另一套大型 Wordnet 資料下載。
- `js/word-lookup.js`：共用可查文字、原生 dialog 字卡、切換語言、裝置發音、收藏與查詞快取。
- 既有 lesson／player 的全文播放行為保留在明確播放按鈕上；點字事件不冒泡。精聽僅揭示文字後建立查詞元素。

### 外部字典邊界

使用 MediaWiki `action=parse` 的 `text|revid`，限定英文語言區段。英文釋義與中文翻譯依各自的詞義群組顯示，不按陣列位置硬配。保留詞條 URL、修訂版號、CC BY-SA 4.0 連結與「已摘錄」說明。不複製引文、外部音檔或圖片。只建立文字節點，不將第三方 HTML 插入活頁面。

第一版的內建詞庫不是完整字典。線上也不保證每個詞都有中文；查不到時明示缺漏並提供來源連結。網路失敗不當作「沒有這個詞」。只在使用者要求時連線，不背景掃描整篇課文。

首版範圍明確限制：110 個內建詞條、8 組課／句詞義規則。詞形採明確對應，不宣稱涵蓋所有變化形。
查詢鍵統一小寫，大小寫敏感的專有名詞可能查不到或得到普通名詞義；不當作通用專名翻譯器。
線上只摘錄前 8 個英文釋義及前 8 組中文翻譯，完整內容以來源為準。英文解釋尚未逐一完成 CEFR 審校。

### 本地儲存

使用現有 `kv` store，無需資料庫升級：

- `dictionaryLanguage`：`zh` 或 `en`。
- `dictionaryCache`：最多 100 個成功的一般字典結果，依最近查詢時間淘汰；不儲存整篇外部 HTML。
- `vocabularyBookmarks`：以詞＋課＋句識別的收藏陣列；保存來源，不混入 SRS 卡片。

匯出學習紀錄加入收藏；cache 不需要備份。現有專案未具備備份還原，本輪不宣稱新增還原。

### 相容性、安全與隱私

- 不改動既有課程 JSON、音檔或 SRS。
- 查詞不使用既有整句 clip ID；單字發音使用裝置語音，實際可用性依裝置。
- fetch 有逾時／AbortController；不帶登入憑證，設定 no-referrer。
- 選取只允許一個已揭示的課文節點；不讀全頁其他文字或表單。盲聽原句除視覺模糊外，也從無障礙樹隱藏，避免螢幕閱讀器先讀出答案。
- 無外部執行程式碼、套件或 API key；離線 shell 要包含所有新增模組。
