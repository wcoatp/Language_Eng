工程 ENG-002；2026-09-22；狀態：本地功能實作、已列 UI 驗收及四組核心音檔完成，整體 check 通過；真機、斷網及全音檔人工聽評仍未完成，未發布。本輪承接使用者「繼續施工」，依既有提案第 10 節先做最小可用版本。

## 範圍與非目標

- 每日故事 `daily-2026-08-23`：核心 6 詞、選用 2 詞，保留 L3；不是 9/22 新課。
- 既有 `l1-05` 外帶午餐：6 項預習、學習目標，不更改原句或音檔。
- 新增 `l1-07` 原創 12 回合「餐點售完時改點」：6 詞、3 題中文理解題、換條件角色任務。正式程度仍 L1，描述為 L1 延伸，建議先學 l1-05。
- 首版只完成提案 A；住宿 B、邀約 C、全課庫預習、AI 對話、客觀口說評量、備份還原、商用稽核及發布不在本輪範圍。
- 音檔補齊授權：使用者回覆「ok」，同意僅將 `l1-07` 的 12 句原創英文送至 Microsoft Edge 語音服務製作美式／英式音檔；不傳附件、個資、學習紀錄或其他課文。先核對待產生清單，不使用強制重製。

## 資料設計

lesson 新增可選 `learning`：`version`、`objectiveZh`、`vocabulary[]`、可選 `task`。舊課無此欄位時完全不啟用。

vocabulary：`id`、`term`、`surface`、`sentenceIds[]`、`zh`、`en`、`example`、`exampleZh`、可選 `optional`。只允許明確英文詞／片語；句 ID 須存在且完整匹配 surface。

task：`id`、`titleZh`、`roleZh`、`setupZh`、`steps[]`（`partner`、`promptZh`、`keywords`、`frame`、`sample`）、`success[]`。這是固定情境自練卡，不會辨識或回應使用者說的內容，介面明示。

questions 可選 `explanationZh`、`sentenceIds[]`。每次開始測驗產生 `{text, originalIndex}` 選項陣列；原 answer 不隨位置改變。記錄原選項索引而不是畫面序號。

`lessonLearningProgress` kv 結構：以 lessonId 為鍵，含 `version`、`vocabulary`、`quiz`、`tasks`。每詞 `heard`（yes/hint/unavailable）、`read`（known/practice）、`at`；各自獨立自評。改版後舊版本不算新規格已完成，覆寫該課當前進度。用 IndexedDB 原子 read-modify-write 避免跨頁覆蓋。匯出原始資料，不新增還原。

## 畫面與生命週期

- `#/prepare/:lessonId`：核心詞一張一張聽與揭示；隨時開始精聽；完成顯示狀態數量、重練不熟／全部、選用補充。
- `#/task/:lessonId`：直接挑戰亦可，不設強制關卡。每步只顯示搭檔一句與中文任務；提示按需選。結尾呈現成功條件與自評，且清楚不是自動評分。
- 詳情頁預習摘要、目標；已編輯課的全文預設摺疊，避免開始暖身前就看到解答。
- 精聽結束提供回課文與換條件任務入口；保留原角色扮演入口。
- 精聽結束只說本輪結束；跳過句子不能宣稱整課掌握，也不能宣稱未評分的句子已加入複習。
- 新頁 render 使用 token 避免路由離開後非同步回覆覆蓋下一頁，destroy 取消語音。保存中禁止重複作答，失敗可重試不偷偷跳過。
