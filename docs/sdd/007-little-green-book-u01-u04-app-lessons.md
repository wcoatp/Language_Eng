# SDD-007｜小綠書 U01–U04 基礎課程實作

- 狀態：已提交、推送並發布（v2026.09.29.3）
- 日期：2026-09-29
- 工程項目：ENG-007
- 上游設計：SDD-004、SDD-005、SDD-006

## 背景與決策

ENG-005 已把小綠書 U01–U04 的溝通功能改寫為四份原創教案，但尚未進入 App。現有 App 的課程資料模型沒有「同一課內的另一段變體聽力」；若把 U01／U03 塞進既有 JSON，會讓使用者無法從課程庫單獨開始、追蹤與分享。

本輪因此把四單元做成 `l1-08`～`l1-11` 四堂可獨立開始的 L1 延伸課。U01／U03 仍以 prerequisite 與文案標示為既有課後的能力延伸，不冒充全新主題；U02／U04 補足目前課程庫缺少的家事協調與服飾試穿。

## 需求

### LGI-01｜四課依序上架至基礎課程

| 教案單元 | App ID | 課程定位 | 前置／承接 |
|---|---|---|---|
| U01 認識新朋友 | `l1-08` | 根據回答追問的自介延伸 | prerequisite `l1-01` |
| U02 家庭對話 | `l1-09` | 釐清家事分工與時間 | 接在 U01 後，非強制先備 |
| U03 餐廳點餐 | `l1-10` | 聽辨另計與 nine/nineteen | prerequisite `l1-05` |
| U04 購物結帳 | `l1-11` | 試穿、不合、替代與決定 | 接在 U03 後，允許不購買 |

- App `level` 一律維持整數 `1`；「L1 延伸」只出現在說明文字。
- 四課在 L1 課程庫依 ID 排序出現，並使用既有學習路線連結。

### LGI-02｜每課有完整可驗證教材

- U01–U03 各 10 回合，U04 12 回合；每句有 A/B 角色、英文、中文與連續句 ID。
- 每課 5 個人工詞卡，含英中、簡單英英、非劇透例句與有效句子引用。
- 每課 3 題理解題，含三個選項、正解、中文解釋與聽力證據句。
- 對話、題目與任務以 ENG-005 審稿稿件為內容基準，不從附件複製人物、地點、長篇原文或音檔。

### LGI-03｜換條件任務可實際操作

- 每課有 3 回合固定角色任務、無提示／關鍵字／句架／示例四層支援。
- 搭檔稱呼依情境顯示「同學／室友／店員」，不再把所有任務硬寫成「店員說」。
- 看過提示後不得記為獨立完成；任務仍是誠實自評，不冒稱客觀口說評分。
- U04 買替代色或禮貌不買都算合理完成。

### LGI-04｜自然口語作為選修加強

- 每課提供 3 組「清楚說法／日常說法」，標示主動練用或先聽懂及使用提醒。
- 每課提供一組短回應、修復、數字聽辨或選擇練習，含示範回合與成功條件。
- 口語加強預設收合，明示建議核心課後再開，避免第一次純聽前洩露台詞。
- 可用裝置語音點播口語句，但不得宣稱已完成真人錄音或真人聽評。

### LGI-05｜30 分鐘核心課整合

- 四課都由 SDD-006 產生六階段 30 分鐘路線。
- 因句數與篇幅適中，核心句應等於全文 10／10／10／12 句。
- 課前預習完成後進核心精聽，理解題與任務沿用既有流程。

### LGI-06｜音訊、離線與版本界線

- 本輪四課設定 `preGeneratedAudio: false`，使用裝置英語語音；不得向 manifest 宣稱已有正式音檔。
- 未來若製作固定聲音，需另案產生完整 voice sets，U03 `nine / nineteen` 需真人實聽辨識度。
- 內容索引、README 課數／句數、App shell 本地版本與 service worker generation 同步。
- 未經當次授權不 commit、push 或 deploy。

## 非目標

- 不複製附件全文、練習頁、圖片或音檔，也不把附件加入版本控制。
- 不在本輪實作同課多變體資料型別；四課使用既有獨立 lesson 模型。
- 不把自然說法列為第一次完成課程的必背條件。
- 不製作、下載或發布固定音檔；不假稱裝置 TTS 已通過真人聽評。
- 不做商用授權結論或整體商用稽核。
- 不以本地自動測試代表學生學習成效。

## 資料與畫面流程

```text
ENG-005 人審稿
  ↓ 人工轉寫、校對引用
l1-08 ～ l1-11 JSON
  ├─ sentences / questions
  └─ learning
      ├─ vocabulary
      ├─ task + partnerLabelZh
      └─ spokenPractice
            ↓
課程頁
  ├─ 30 分鐘核心路線
  ├─ 課前字詞 → 核心精聽 → 理解題 → 換條件任務
  └─ 收合的口語加強（裝置語音點播）
```

## 相容性與安全

- 沒有 `spokenPractice` 或 `partnerLabelZh` 的 111 堂舊課沿用原畫面與預設稱呼。
- 新課不新增資料庫 store，不改 SRS key、備份格式或舊課 ID。
- 口語點播只把所選句子交給本機裝置語音，不傳送課文、進度或 API key。
- `learningProblems()` 驗證新增 metadata，避免空字串、錯誤 mode 或缺少回合在 build 後才爆出。
