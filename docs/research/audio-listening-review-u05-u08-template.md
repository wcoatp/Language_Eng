# U05–U08 合成音檔人工聽評表

對應 [SDD-011](../sdd/011-little-green-book-u05-u08-app-lessons.md)。這是空白檢查表，不代表已由人工聽完；HTTP 200、ffprobe 或瀏覽器尺寸檢查都不能替代聽感判斷。

## 聽評方式

1. 在正式站開啟課程播放器：[U05 維修約訪](https://echo-english-20260814.web.app/#/play/l2-09)、[U06 住宿費用](https://echo-english-20260814.web.app/#/play/l2-10)、[U07 診所登記](https://echo-english-20260814.web.app/#/play/l2-11)、[U08 道路支援](https://echo-english-20260814.web.app/#/play/l2-12)。
2. 每一列選指定 voice set，播放列出的句子 ID。先只聽，再核對句意；確認 A/B 容易區分、否定／數字／預估語氣清楚、語速適合 L2。
3. 填「清楚／需修正／無法判斷」，有問題時寫句子 ID、聲線組與具體聽感。不可只寫「怪」。不要錄音或填聽者真實姓名。
4. 本表只抽查每課關鍵句，不是 160 段逐句聽評，也不是教學成效評估。若要完整逐句驗收，另附逐句核對結果。
